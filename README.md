# Obsidian Only Tabs

A lightweight Obsidian plugin that replaces the native single-line tab strip with an independent tab panel.

## Current scope

- Independent tab panel.
- Vertical list layout.
- Click to activate a tab.
- Middle click to close a tab.
- Active tab highlighting.
- Same-group and cross-group drag sorting.
- Optional native tab strip hiding.
- List and card presentation styles.
- Optional file icons.
- Lazy context menu with close actions.
